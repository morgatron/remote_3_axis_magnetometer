# Legacy Termux USB-OTG Scripts Archive

This directory contains early prototypes for reading serial data over physical USB-OTG cables on Android phones running Termux.

These scripts have been superseded by the wireless **Bluetooth 5.0 LE Coded PHY $\to$ 1 Mbps BLE Gateway** architecture, which allows wireless field monitoring directly via the **nRF Connect** app or `scripts/ble_monitor.py`.
